# Module Migrator

Una extensión para VS Code diseñada para automatizar la migración de proyectos
CommonJS (require / module.exports) a ES Modules (import / export) de forma
interactiva y recursiva.

## Características

- Navegador interactivo de directorios.
- Migración automática de CommonJS a ESM.
- Saneamiento en cadena de dependencias e importaciones.
- Soporte para dotenv nativo.
